# 洞穴全景漫游生成器 (Cave Panorama Builder)

这是一个用于制作洞穴、古建和展厅沉浸式全景漫游的 AI Skill。它能帮助拆解参考画面与交互，准备等距柱状全景素材，并利用 Pannellum 实现探灯揭幕、拖拽视角、多场景热点等功能。

## 🚀 如何使用
将本仓库克隆或下载到你的本地 AI 助手（如 Claude Code、OpenClaw 等）指定的 Skills 目录中即可。

- 点亮洞穴
- 敦煌意象全景
