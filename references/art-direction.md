# 画面与互动艺术规范

适用：用户想迁移参考中的视觉与交互语言。保留用户指定的题材和品牌；以下色号、尺寸与时长是建议起点，不是从原源码提取的数值。

## 画面：暖色矿物质感的洞窟展陈

核心不是给网页加金色，而是让画面拥有“岩壁厚度、颜料年代感、局部光照和安静的观看距离”。

| 元素 | 参考特征 | 可实施设置 |
|---|---|---|
| 暗场 | 深黑、暖褐、微光 | 背景 `#0D0B09`，遮罩接近黑而非高饱和蓝 |
| 主色 | 赭石、黄土、沙金 | 岩壁 `#8F6744`，浅石 `#C6AD82`，点缀金 `#D3B77B` |
| 辅色 | 褪色青绿、暗朱红 | `#637C73`、`#8D5142`，控制面积与饱和度 |
| 文字 | 金色题签、传统书卷气质 | 标题用可用的宋/楷风格，正文优先可读；不要声称识别出原字体 |
| 控件 | 半透明深褐底、细金描边、圆环 | 1px 边线、柔和小范围光晕；避免大面积金属反光 |
| 纹理 | 风化岩壁、斑驳矿物颜料、浅浮雕 | 用合格全景素材承载，别给 UI 全局添加重噪点 |
| 光 | 佛像及壁画局部亮，角落保留暗部 | 提前在素材中形成主光；CSS 揭幕只改变可见性 |

画面构图：空间铺满视口。首机位把主体放在初始视向附近，左上保留短题签，右上放解读入口，底边容纳熄灯、复位与场景目录。热点尽量落在可解释的入口/壁画附近；不要同时覆盖主像面部与主要细节。

桌面标题可从 26–34px 开始，正文 14–16px；手机标题 20–26px，正文不少于 14px。按钮触摸区域建议至少 44px。尊重手机安全区，窄屏缩减题签描述，让场景目录横向滚动，不遮挡灯光入口。

## 互动：由暗到明、慢速探索、按需解读

| 环节 | 用户意图 / 反馈 | 实现载体 | 推荐起点 |
|---|---|---|---|
| 暗场探灯 | 指针附近只看到一小部分，中心点亮入口始终清楚 | 罩在全景上的径向渐变，`pointermove` 更新中心 | 光圈半径约 110–160px；触屏给固定微光和显式按钮 |
| 点亮 | 按一次，空间逐渐显露，控件随后出现 | 同一遮罩淡出，状态锁防重复触发 | 900–1400ms；减少动态效果时约 0–100ms |
| 环视 | 拖动像转头，松开缓慢停下 | Pannellum yaw / pitch 与摩擦 | 初始 HFOV 80–100°，缩放约 50–110°，按素材调整 |
| 热点 | 细金圆环、箭头/文字说明目的地 | 球面坐标热点 + 真正的按钮 | 只突出少量相关热点，轻微脉动可选 |
| 切景 | 淡出后到达明确场景，加载时有反馈 | 场景图、引擎 `load / error` | 过渡 350–650ms；不以固定时长假装资源就绪 |
| 解读 | 看细节时读短文，关后继续原视向 | `dialog` 或侧面板，停止自动环视 | 开合 150–250ms，Esc 关闭，焦点恢复 |
| 熄灯 | 从探索返回最初的发现状态 | 独立灯光状态，不重新下载图片 | 400–800ms；不删除场景数据 |
| 复位 | 迷失方向时回到当前机位的初始构图 | `lookAt(pitch, yaw, hfov)` | 约 500ms；减少动态效果时直接定位 |

交互次序要成立：资源准备好 → 可点亮 → 可探索 → 可切景。任何加载失败都应给出可读状态和静态替代。不要用强烈闪白、连续甩镜或强制自动旋转制造“沉浸感”。

## 可迁移到其他题材的部分

保留“发现、揭幕、探索、解读”的结构，替换场景材质和题签语言即可用于古建、矿洞、旧工厂、科幻舱室。全景投影与热点系统不变；光圈大小、材质配色、控件形状应随题材调整。

检查设计时，问三个具体问题：第一眼是否看懂点哪里；镜头变化后热点是否仍贴住对象；关闭信息后是否还处在刚才的视向。比装饰数量更重要。
